# Bibliotecas de sensores

Dependências binárias geradas por `python scripts/fetch_hardware_monitor.py`.
Versão fixa: LibreHardwareMonitor 0.9.6 (.NET Framework).
O script verifica o SHA-256 do pacote e dos textos de licença. Os DLLs são
ignorados no Git e incluídos no executável pelo fluxo de build.

Código-fonte e releases:
https://github.com/LibreHardwareMonitor/LibreHardwareMonitor/tree/v0.9.6

A biblioteca e seus módulos PawnIO não foram modificados. `LICENSE` e
`THIRD-PARTY-NOTICES.txt` acompanham o pacote distribuído.
O driver PawnIO é instalado separadamente a partir de https://pawnio.eu.
